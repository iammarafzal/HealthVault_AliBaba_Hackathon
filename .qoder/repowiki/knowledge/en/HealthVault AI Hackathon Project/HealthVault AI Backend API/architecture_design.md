The application follows a layered FastAPI layout under `app/`: `api/v1/` exposes REST endpoints (auth, biomarkers, emergency, interactions, interpreter, planner, summary, vault, voice) mounted via `api/router.py`; `models/` defines SQLAlchemy ORM entities (user, record, allergy, medication, biomarker); `schemas/` holds Pydantic request/response models; `services/` encapsulates external integrations (ASR speech-to-text, OCR via PaddleOCR, OSS object storage); `agents/` implements a LangGraph multi-agent workflow (`graph.py`) orchestrating OCR, routing, document parsing, drug-guard validation, and DB sync through specialized agents (`extraction_agent`, `interaction_agent`, `summary_agent`, `voice_agent`) sharing a common `state.py`. `core/` provides shared infrastructure: `config.py` loads settings from `.env` via pydantic-settings, `database.py` configures async SQLAlchemy + asyncpg engine, `security.py` handles JWT auth with python-jose/passlib. The app entry point is `app.main.py`, served by uvicorn on port 8000 as defined in the Dockerfile, with all secrets and feature flags driven by environment variables documented in `.env.example`.
